# STAR LEAP ガチャ縛り編成帳

ガチャを一切回さないプレイ向けの非公式・静的編成ツールです。抽選なしで確定入手できる版のキャラに限定します。

## 使い方

`index.html` を静的サーバーで開きます。GitHub Pages では main ブランチのルートから公開できます。キャラ一覧で所持・0～6凸・攻略タグを記録し、編成タブで前列3、後列3、支援1を配置します。データはブラウザ内へ自動保存され、JSONでバックアップと移行ができます。

## 開発

`npm test` で保存形式・編成制約・掲載基準を検証します。依存パッケージは不要です。資料と掲載基準は `SOURCES.md` を参照してください。

46版の顔アイコンは `assets/portraits/` に格納し、版ごとの出典は `assets/portrait-sources.json` に記録しています。画像の権利は ©Konami Digital Entertainment に帰属します。
